# Instrucciones para asistentes de código

Antes de responder o cambiar archivos de este proyecto:

0. La raíz del repositorio es `Python-Project`. La carpeta `.asistente/` está en esa raíz, un nivel arriba de `prueba/`; si trabajas desde `prueba/`, usa `../.asistente/` para llegar a ella. No concluyas que falta por buscar solo dentro de `prueba/`.
1. Lee `.asistente/MEMORIA_PROYECTO.md` y las notas `.asistente/` relevantes (desde `prueba/`, `../.asistente/`).
2. Para preguntas sobre el estado actual, consulta `.asistente/MAPA_PROYECTO.md` (desde `prueba/`, `../.asistente/MAPA_PROYECTO.md`) y verifica el código fuente pertinente. Actualiza el mapa si el trabajo cambia el estado documentado.
3. Trata mapas en `mapas/` con fechas antiguas como referencias históricas.
4. Respeta las preferencias de interacción y el siguiente trabajo pendiente descritos en la memoria del proyecto.
