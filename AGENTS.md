# Instrucciones para asistentes de código

Antes de responder o cambiar archivos de este proyecto:

1. Lee `.asistente/MEMORIA_PROYECTO.md` y las notas `.asistente/` relevantes.
2. Para preguntas sobre el estado actual, actualiza o consulta `.asistente/MAPA_PROYECTO.md` y verifica el código fuente pertinente.
3. Trata mapas en `mapas/` con fechas antiguas como referencias históricas.
4. Respeta las preferencias de interacción y el siguiente trabajo pendiente descritos en la memoria del proyecto.
